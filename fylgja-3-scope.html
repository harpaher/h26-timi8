Æfing 6: 🤔 Spáðu fyrir – hvað prentast?

Skrifaðu svarið niður ÁÐUR en þú smellir á „Sýna svar“.

a)20 og svo 10. Inni í f() er búin til ný local breyta x. Global x breytist ekki. 

let x = 10;

function f() {
  let x = 20;
  console.log(x);
}

f();
console.log(x);
Sýna svar

20 og svo 10. Inni í f() er búin til ný local breyta x. Global x breytist ekki.

b)ReferenceError: y is not defined. y er local í g() og er horfin þegar g() klárast. 

function g() {
  let y = 5;
}

g();
console.log(y);
Sýna svar

ReferenceError: y is not defined. y er local í g() og er horfin þegar g() klárast.

c)6 og svo ReferenceError: i is not defined. summa er fyrir utan loopuna og lifir áfram, i er bara til inni í loopunni. 

let summa = 0;

for (let i = 1; i <= 3; i++) {
  summa += i;
}

console.log(summa);
console.log(i);
Sýna svar

6 og svo ReferenceError: i is not defined. summa er fyrir utan loopuna og lifir áfram, i er bara til inni í loopunni.

d)teljari er global, svo allar þrjár keyrslur breyta sömu breytunni. 

let teljari = 0;

function auka() {
  teljari++;
}

auka();
auka();
auka();
console.log(teljari);
Sýna svar

3. teljari er global, svo allar þrjár keyrslur breyta sömu breytunni.
